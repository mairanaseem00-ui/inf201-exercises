# INF201 – Deliverable 3

This project is part of INF201 and focuses on object-oriented programming (OOP) in Python. The assignment involves creating a simple RPG battle simulator using classes, inheritance, and methods.

## Tasks

- **Task 1 – Character:** Created a Character class with methods for attacking, taking damage, and healing.
- **Task 2 – Dice:** Created a Dice class to generate random damage values.
- **Task 3 – Weapon:** Created a Weapon class and added optional weapons to characters.
- **Task 4 – Warrior and Mage:** Created subclasses with armor and mana abilities.
- **Task 5 – Battle:** Created a Battle class to simulate turn-based combat.

## Files

- `game_simulator_v1.py` – Character, Warrior, Mage, and Battle classes.
- `dice.py` – Dice class.
- `items.py` – Weapon class.
- `deliverable_03-solution.ipynb` – Testing and results.
- `requirements.txt` – Project dependencies.

## Running the Project

The project was developed in Python using VS Code and Jupyter Notebook.

The notebook contains tests and results for each task. Run the notebook cells in order to test the classes and simulate battles.
